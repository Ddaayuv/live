# بوت المراسلة (Telegram Anonymous Messaging Bot)

بوت تليجرام بلغة بايثون يتيح للمستخدمين إرسال رسائل تصل مباشرة إليك (المطوّر)، مع لوحة تحكم كاملة تضم كل الميزات التالية:

- 📖 طريقة استخدام أوامر البوت
- ✳️ تغيير الرد التلقائي
- ✳️ تغيير رسالة الترحيب
- ✅ تفعيل/تعطيل إظهار هوية المرسل
- 📢 الاشتراك الإجباري (إضافة/حذف قنوات)
- 📊 الإحصائيات
- 🚫 قائمة المحظورين (حظر/فك حظر)
- 📮 إذاعة رسالة لكل المشتركين
- ⚙️ إعدادات أخرى (تشغيل/إيقاف البوت)
- المراسلة تتم مباشرة: أي رسالة من المستخدم تصل للمطوّر، وأي Reply من المطوّر على تلك الرسالة يصل تلقائياً للمستخدم.

## 1. التثبيت

```bash
pip install -r requirements.txt
```

يتطلب Python 3.10 أو أحدث.

## 2. الحصول على التوكن والآيدي

1. أنشئ بوتاً جديداً عبر [@BotFather](https://t.me/BotFather) على تليجرام واحصل على التوكن (Token).
2. احصل على آيدي حسابك الشخصي عبر بوت مثل [@userinfobot](https://t.me/userinfobot).

## 3. التشغيل

عبر متغيرات البيئة (الطريقة الموصى بها):

```bash
export BOT_TOKEN="ضع_التوكن_هنا"
export ADMIN_IDS="123456789,987654321"   # يمكن وضع أكثر من آيدي مفصولين بفاصلة
python3 bot.py
```

أو عدّل القيم مباشرة في أعلى ملف `bot.py`:

```python
BOT_TOKEN = "ضع_التوكن_هنا"
ADMIN_IDS = [123456789]
```

## 4. طريقة الاستخدام

- أي مستخدم يرسل `/start` سيحصل على رسالة الترحيب، وإذا كان هناك اشتراك إجباري سيُطلب منه الاشتراك أولاً.
- أي رسالة يرسلها المستخدم (نص، صورة، فيديو...) تصل تلقائياً للمطوّر مع بيانات المُرسل (إن كانت خاصية إظهار الهوية مفعّلة)، ويصل المستخدم رد تلقائي فوري.
- المطوّر يفتح لوحة التحكم بالأمر `/admin`.
- للرد على مستخدم مُعيّن: يقوم المطوّر بعمل **Reply** على الرسالة المُوجَّهة إليه، ويُرسل ردّه — يصل الرد تلقائياً لذلك المستخدم فقط.
- الاشتراك الإجباري: يجب أن يكون البوت **مشرفاً (Admin)** في القناة حتى يستطيع التحقق من اشتراك المستخدمين.

## 5. تخزين البيانات

يستخدم البوت ملف `data.json` يُنشأ تلقائياً بجانب `bot.py` لتخزين:
- إعدادات البوت (رسالة الترحيب، الرد التلقائي، حالة الهوية، قنوات الاشتراك الإجباري...)
- قائمة المستخدمين
- قائمة المحظورين
- الإحصائيات

> ملاحظة: هذا التخزين بصيغة JSON بسيط ومناسب للاستخدام الصغير/المتوسط. لعدد مستخدمين كبير جداً، يُفضّل استبداله بقاعدة بيانات مثل SQLite أو PostgreSQL.

## 6. تشغيل دائم (اختياري)

لتشغيل البوت باستمرار على سيرفر (Linux)، يمكن استخدام `systemd` أو `screen` أو `tmux`، أو أدوات مثل `pm2`/`supervisor`.

مثال بسيط عبر `tmux`:

```bash
tmux new -s mybot
python3 bot.py
# اضغط Ctrl+B ثم D للخروج دون إيقاف البوت
```
